讓同事自己填單，讓負責訂便當的人更快完成統計。

Windows 主持端在辦公室區域網路開團，同事透過手機或電腦瀏覽器填寫訂單，主持人集中查看、修改與匯出結果。

## 適合什麼情境？

- 辦公室有一位同事負責收集大家的便當訂單。
- 希望減少在群組訊息中逐筆抄寫、加總的工作。
- 有一台可在訂餐期間保持運作的 Windows 電腦。
- 主持端與填單者能使用互通的辦公室網路；手機通常需要連辦公室 Wi-Fi。

## 使用流程

1. 主持人啟動工具，選擇菜單圖片，設定部門或群組。
2. 開始訂餐，分享入團網址或 QR Code。
3. 同事開啟瀏覽器，填寫姓名或代稱、餐點、單價與數量。
4. 主持人核對訂單、必要時修改，並在截止時收團。
5. 查看統計、標記收款及匯出結果。

實際操作與功能以各版本隨附的使用說明為準。

## 使用前先了解

- 主持端需保持開機並執行工具；同事不需安裝 App。
- 同一個 Wi-Fi 名稱不代表裝置一定互通，訪客網路可能隔離裝置。
- 目前以一天一份訂餐資料為範圍，並非午餐、晚餐與多間店家的獨立多團系統。
- 餐點與單價由填單者輸入，主持人仍需核對菜單。
- 請只在可信任的辦公室區網使用，入團連結不要公開貼到社群。
- 更新前先備份資料；請勿將含員工及訂單資料的資料夾與備份公開上傳。
